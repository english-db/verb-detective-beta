# VerbDetective

Socle de fusion pour le projet `Verb Detective`.

Structure prévue:
- `index.html` pour la page titre et l'orientation
- `part.html` pour charger une partie via `?part=1..4`
- `js/` pour le moteur partagé
- `js/parts/` pour les configurations de chaque partie
- `assets/` pour les images, sons et ressources communes

Pour lancer le projet localement:
- `node serve.mjs`
- puis ouvrir `http://localhost:8000/`
